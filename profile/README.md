## @sdlc-harness

This organisation used to hold `@sdlc-harness`, the command handle of an autonomous software-delivery
harness for Claude Code. The harness is now **[DevScene](https://github.com/firu-daniel/devscene)**, and its
command handle is **[`@dev-scene`](https://github.com/dev-scene)**.

- **`@sdlc-harness` no longer controls anything.** In a repository that has adopted DevScene, start the
  comment's first line with `@dev-scene` instead.
- **It is not a bot or a user account.** This organisation receives nothing and notifies no one, and it holds
  no code. It is kept only so that the name cannot be taken by someone else.
