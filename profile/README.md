## @sdlc-harness

This organisation holds the name `@sdlc-harness`, the command handle of
[autonomous-sdlc-harness](https://github.com/firu-daniel/autonomous-sdlc-harness), an autonomous
software-delivery harness for Claude Code.

You probably got here by clicking `@sdlc-harness` in an issue or pull-request comment. In a repository that has
adopted the harness, a comment whose first line starts with `@sdlc-harness` controls the harness run linked
to that issue or pull request.

- **It is not a bot or a user account.** The adopting repository's own workflow reads the comment's text. This
  organisation receives nothing and notifies no one, and it holds no code.
- **Type the handle in full.** It does not autocomplete.
- **Only people with write access** to the repository can issue a command. Commands from anyone else are
  refused.
